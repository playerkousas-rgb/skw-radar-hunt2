# 🎯 Radar Hunt v2.0 - GPS 真人尋寶雷達

一個手機優先的 Progressive Web App (PWA)，讓領袖可以建立尋寶地圖、開房間，邀請多位玩家同步出發，使用 GPS 雷達找寶藏，最後繳交驗證碼統計成績。

## ✨ 功能特色

### 📱 手機友善 (Mobile First)
- 原生 PWA 支援，可加到主畫面
- 全螢幕體驗，支援 iPhone 瀏海 (Safe Area Insets)
- 防止 iOS 點擊縮放、彈跳刷新
- 大尺寸按鈕與觸控目標（≥ 44px）
- 深色模式 UI，適合戶外活動
- 音效 + 震動反饋

### 🛰️ GPS 準確度提升
- **卡爾曼濾波器 (Kalman Filter)**：平滑 GPS 軌跡，減少飄移
- **異常值過濾**：自動排除不合理的 GPS 跳點（超過合理跑步速度的位移）
- **精度品質指示器**：即時顯示 GPS 訊號等級（極佳/良好/一般/弱）
- **觸發半徑自適應**：依 GPS 精度動態調整觸發範圍，避免假陽性
- **移動距離過濾**：距離增量需超過 GPS 誤差 30% 才計入總距離，避免抖動

### 🎮 三種玩法 × 三種計時（v2.4）

建立地圖時可選擇**玩法模式**與**計時方式**：

| 玩法 | 說明 |
|---|---|
| 🏆 **奪分式** | 自由次序搶分；每個 CP 可設分數（1/2/3/5/10/20，**未設預設 1 分**），地圖標示 ⭐分數方便攻略 |
| 🧭 **越野式** | 檢查點須**依指定次序**完成；編輯器用 ▲▼ 排定次序，未輪到的 CP 在地圖顯示 🔒 灰階、靠近也不會觸發 |
| 🎯 **自由尋寶** | 無規則，純粹找到全部寶藏（只需設定計時） |

| 計時 | 說明 |
|---|---|
| ⏱️ **計時模式** | 向上計時，越快越強（預設） |
| ⏳ **倒計時模式** | 限時（5–45 分鐘），剩 60 秒轉紅警示，**時間到自動結算成績** |
| 🚫 **不限時** | 完全不顯示計時，輕鬆玩 |

另有两個顯示選項：
- 📍 **顯示自身位置**（預設開）：關閉後地圖不顯示你的位置點，且地圖改以寶藏中心定位（不會從視角洩露站位），考驗方向感；GPS 仍在背景記錄
- 🔔 **提示目標在附近**（預設開）：關閉後接近寶藏不再有提示音、「在範圍內」通知與震動

所有設定自由組合（例：奪分式 + 倒計時 15 分 + 隱藏位置 + 無提示 = 硬核定向搶分賽），並可與個人計時模式疊加 — 各人掃碼後自行倒數出發、各自起算。

### ⏱️ 個人計時模式（最公平，推薦）
- 領袖開房間時開啟「個人計時模式」，可選 10/15/30/60 秒
- 成員掃 QR／點連結後，App 自動倒數（預設 30 秒）後出發
- **計時從各人自己出發那一刻起算** — 出發時間不同也完全公平
- 找齊全部寶藏或回到終點繳交成績，用時即個人成績；中途重新整理計時不會歸零

### 👥 多人同步遊玩（無需後端）
- **6 位房間代碼**：領袖建立房間後產生易讀的房間代碼（避開易混淆字元）
- **QR Code 加入**：分享 QR Code，成員掃描即自動匯入地圖與房間代碼
- **同步倒數開始**：
  - 領袖點「開始」後設定倒數秒數（3/5/10/15/30/60 秒）
  - 產生「開始連結」與 QR Code，分享給成員
  - 成員點擊連結後自動同步倒數
  - 也可在等待頁面手動輸入開始代碼
- **等待大廳**：加入房間後會進入等待畫面，顯示 GPS 狀態與就緒指示

### 🏁 完成與成績系統
- **完成畫面**：找到全部寶藏後顯示華麗的完成動畫與統計數據
- **⭐ 奪分模式**：每個寶藏可自訂分數（預設 1 分），地圖上直接標示 ⭐分數，方便成員規劃攻略路線；成績/驗證碼/排行榜都以分數排序
- **驗證碼機制**：每位玩家完成後得到一個 `ROOM-XXXX` 格式驗證碼
- **領袖成績輸入**：領袖在房間頁面輸入驗證碼即可登錄成績
- **即時排行榜**：前三名有頒獎台動畫，顯示用時與找到寶藏數
- **成績分享**：一鍵分享成績到 LINE / WhatsApp / 郵件 / 系統分享

### 🗺️ 地圖編輯器
- 互動式 Leaflet 地圖（深色模式）
- 點擊地圖放置寶藏點
- 支援地名搜尋（Nominatim API）
- 4 種寶藏類型：文字、圖片、表情符號、連結
- 可設定提示 (hint)、觸發半徑（1m–50m）與 **⭐ 分數（1/2/3/5/10/20，奪分模式）**
- 快速放置按鈕

### 🏆 成就系統
- 🎯 初次探索、🏆 尋寶獵人、👑 大師獵人
- ⚡ 速通達人（5 分鐘內完成）、🏃 跑者（10km）
- 💎 完美尋寶（100% 完成）

## 🚀 使用方式

### 領袖
1. 選擇「我是領袖」
2. 輸入你的名字
3. 創建地圖 → 在編輯器中點擊地圖放置寶藏
4. 設定每個寶藏的名稱、表情、半徑、提示
5. 回到領袖中心，點「🚀 開房間！開始多人遊戲」
6. 分享房間代碼或 QR Code 給玩家
7. 玩家都加入後，設定倒數秒數，點「開始」
8. 分享開始連結/QR Code（讓玩家點擊同步倒數）
9. 玩家完成後會拿到驗證碼，你輸入即可記錄成績

### 玩家
1. 選擇「我是玩家」，輸入你的名字
2. 掃描領袖的 QR Code 或點擊分享連結
3. 自動進入加入流程，確認房間代碼與地圖
4. 等待領袖開始（會自動倒數）
5. 倒數結束後開始用雷達找寶藏
6. 靠近寶藏時會有音效、震動與屏幕閃光提示
7. 全部找到後會顯示驗證碼，交給領袖登記

- 全 App 統一版權聲明：**COPYRIGHT © 2026 SCOUT SYSTEM**（首頁 / 說明 / 設定 / 分享 HTML / PWA manifest）

### 重大修正（Bug Fixes）
1. **同步開始連結失效**：地圖指紋（checksum）原本包含 `map.id`，但成員匯入時會重新產生 id，導致「開始連結」永遠驗證失敗。已改為只依寶藏座標計算，跨裝置可同步倒數。
2. **領袖無法驗證跨裝置成績**：驗證碼原本只是隨機碼，領袖手機上根本沒有該成績。現在玩家完成後可提供「完整成績代碼」（自帶姓名/時間/成績），領袖貼上即自動登錄並計入排行榜。
3. **地圖 iframe 閃爍**：GPS 每次更新都重建整個地圖 iframe（地圖會重新載入、失去縮放）。改為 postMessage 即時更新位置與待放置標記。
4. **「清除進度」無效**：雷達頁清除後會被 App 狀態同步還原。已改由 App 層統一清除（儲存 + 狀態一致）。
5. **重新整理/重掃 QR 會遺失進度**：匯入相同地圖（座標相同） now 保留原 map id，已找到的寶藏進度不會消失。
6. **首頁改名會重設所有設定**：現在與既有設定合併，不會再把音效/震動/語言打回預設。
7. **排行榜重複 key**：同一玩家多次成績使用相同 id，改為每筆唯一 id。
8. **「GO!」畫面從未出現**：倒數結束直接跳 0 秒，現在有短暫 GO! 停留。
9. **空地圖死路**：0 個寶藏的地圖會卡在「沒有待尋寶藏」，現在提供重新導入指引。
10. **缺少 PWA 圖示**：manifest / apple-touch-icon 引用的 PNG 不存在，已補齊（192/512/180）。

### 功能加強（v2.2 奪分模式）
- **⭐ 檢查點分數**：領袖編輯寶藏時可設定分數（1/2/3/5/10/20，未設為 1 分）；地圖標記直接顯示 ⭐分數，成員可據此規劃攻略（搶高分點 vs 快速掃點）。
- 分數貫穿整個流程：雷達頁頂部分數條、找到寶藏 +N 分回饋、成績頁得分橫幅、驗證碼自帶分數、領袖成績榜與排行榜以分數排序。
- 領袖開始遊戲後顯示「口頭開始代碼」（`START-…`），成員在等待頁用 🔑 輸入即可同步；遲到點擊開始連結也會立即開始（不再無回應）。
- 領袖房間頁新增「開始 QR 碼」開關，方便補掃。
- 驗證失敗時顯示錯誤訊息（原本只有音效）。
- 領袖驗證成績會同步寫入排行榜；排行榜分享文字改用實際玩家名稱（原本固定找「我」永遠找不到）。
- 成績榜顯示步行距離；匯入欄位支援直接貼上完整分享連結（自動抽出的圖資料）。

- **⏱️ 個人計時模式**：房間頁可開啟「個人計時模式」(10/15/30/60秒)，成員掃碼/開連結後自動倒數出發、各自起算用時 — 出發時間不同也最公平；另修正 QR 加入流程地圖不會自動帶入的問題。
- **🎮 玩法模式**（v2.4）：奪分式（CP 分數）/ 越野式（依序完成，▲▼ 排次序，未輪到的鎖定不觸發）/ 自由尋寶；計時方式：計時 / 倒計時（限時自動結算）/ 不限時。
- **📍顯示選項**（v2.5）：可關閉「自身位置顯示」（地圖改以寶藏中心定位）與「目標在附近提示」（無提示音/通知），支援硬core玩法。
